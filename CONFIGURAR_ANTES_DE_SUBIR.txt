ANTES DE SUBIR A GITHUB
=======================

1. Abre:
   js/config.js

2. Reemplaza únicamente:

   PEGA_AQUI_TU_PROJECT_URL

   por algo similar a:
   https://xxxxxxxxxxxx.supabase.co

3. Reemplaza:

   PEGA_AQUI_TU_PUBLISHABLE_KEY

   por tu Publishable key / anon key.

4. NO coloques la service_role key en este proyecto.

5. Guarda js/config.js.


CÓMO SUBIRLO AL REPOSITORIO
===========================

IMPORTANTE:
No subas este ZIP directamente.

1. Descomprime este ZIP en tu computadora.
2. En GitHub, dentro de mycitago/app:
   Add file > Upload files
3. Sube TODO EL CONTENIDO de la carpeta descomprimida:
   - index.html
   - admin
   - css
   - js
   - .nojekyll
   etc.
4. Haz Commit changes.

ACTIVAR GITHUB PAGES
====================

GitHub:
Settings > Pages

Source:
Deploy from a branch

Branch:
main

Folder:
/ (root)

Save.

La dirección esperada será:
https://mycitago.github.io/app/
