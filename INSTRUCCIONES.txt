MYCITAGO — SIDEBAR V2 DEL SHELL REAL
====================================

OBJETIVO
--------
Normalizar de una sola vez el sidebar real ct-*:
- altura uniforme de filas;
- Servicios / Equipo / Sucursales con el mismo ritmo vertical;
- grupos con espaciado consistente;
- texto desktop de 13px;
- iconos Lucide homogéneos;
- active / hover / focus profesionales;
- mobile sin cambios.

ARCHIVOS DE PRODUCCIÓN AFECTADOS
--------------------------------
js/citago-shell.js
css/citago-admin.css

NO TOCA
-------
- ct-mobile
- topbar
- Dashboard
- rutas
- permisos
- backend
- hideLegacy()
- contenido de páginas

INSTALACIÓN
-----------
1. Descomprime este ZIP en la raíz del repositorio.
2. Ejecuta:

   python APLICAR_SIDEBAR_V2.py

3. Revisa git diff.
4. Deben cambiar únicamente:
   js/citago-shell.js
   css/citago-admin.css

5. Sube esos dos archivos a GitHub.

POR QUÉ SE USA UN APLICADOR
---------------------------
El script parchea la versión ACTUAL de tus dos archivos en vez de entregarte
copias completas potencialmente desactualizadas. Así conserva el topbar real,
dropdown, acciones y cualquier cambio reciente ya existente.

CAMBIO DE ICONOS
----------------
Desktop usa Lucide mediante data-lucide y la llamada createIcons() que el shell
ya ejecuta. Mobile conserva los símbolos actuales; no se rediseña.

CHECKLIST VISUAL
----------------
- MI NEGOCIO:
  Servicios, Equipo y Sucursales deben tener exactamente la misma altura y
  separación.
- CRECIMIENTO y ADMINISTRACIÓN deben repetir el mismo patrón.
- El activo debe verse claramente sin aumentar la altura de su fila.
- Tab debe mostrar foco visible.
- Ninguna ruta debe cambiar.
- Mobile debe verse igual que antes.
