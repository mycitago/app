MYCITAGO · PAQUETE MAESTRO ÚNICO
=================================

Este ZIP reúne en una sola entrega:
A) Dashboard del negocio estabilizado.
B) Regla de timeout para datos (12 segundos).
C) RPC business_dashboard_snapshot segura.
D) Reserva pública adaptativa premium ya preparada.
E) P0 de reserva conservado mediante RPC seguras.

ORDEN OBLIGATORIO
-----------------
1. En Supabase SQL Editor ejecuta:
   sql/BUSINESS_DASHBOARD_SNAPSHOT.sql

   Resultado esperado:
   business_dashboard_snapshot | p_business_id uuid | true

2. NO vuelvas a ejecutar P0_RPC_PUBLICAS_REFERENCIA.sql si tus tres RPC
   públicas ya existen y reservar.html ya funciona. Ese archivo queda
   solamente como respaldo.

3. Sube/reemplaza en GitHub, respetando rutas:
   admin/index.html
   reservar.html
   css/booking-adaptive.css
   js/data-state.js
   js/dashboard-data-loader.js
   js/admin-dashboard-pro.js
   js/booking-category-presets.js
   js/adaptive-booking.js
   js/services.js
   js/appointments.js
   js/app.js

DASHBOARD — QUÉ CAMBIA
----------------------
- Deja de depender de Promise.all de tres consultas separadas para el resumen.
- Usa una sola RPC: business_dashboard_snapshot.
- La RPC valida que el usuario pertenezca al business_id (o sea Super Admin).
- Timeout máximo: 12 segundos.
- Si falla: KPIs no quedan eternamente en "Cargando"; aparece error + Reintentar.
- Si no hay datos: los renderizadores existentes muestran estados vacíos.
- Trial y "Siguiente paso" permanecen en los archivos base, no se eliminan.

PRUEBAS DASHBOARD
-----------------
Negocio vacío:
- Citas hoy = 0.
- Por confirmar = 0.
- Ingresos = $0.00.
- Agenda: "No hay citas programadas para hoy".
- Próximas: "No hay próximas citas".
- Actividad: estado vacío.
- Nunca "Cargando..." infinito.

Negocio con datos:
- KPIs deben coincidir con citas reales.
- Agenda, próximas citas y servicios deben aparecer.
- El banner de trial sigue funcionando.

RESERVA PÚBLICA
---------------
Flujo:
Servicio → Fecha/Hora → Datos → Confirmación.

El diseño se adapta por business_category_id:
- dental
- estética / beauty
- barbería
- veterinaria
- psicología
- spa
- fallback genérico

P5 NO INCLUIDO
--------------
No agrega pagos online, recordatorios, correo, reagendar ni cancelar.

ROLLBACK
--------
Si el Dashboard falla después de ejecutar la RPC, no borres la función.
Restaura únicamente admin/index.html y js/admin-dashboard-pro.js desde GitHub
y envía el error exacto de Console/Network.
