MYCITAGO · AJUSTE LIMITADO DE SERVICIOS
========================================

OBJETIVO
--------
Este paquete corrige el problema detectado en Servicios sin hacer todavía
el rediseño visual completo.

CORRIGE
-------
1. Una plantilla que ya existe ACTIVA muestra "Editar" y no se puede duplicar.
2. Una plantilla que existe DESACTIVADA muestra "Reactivar".
3. Reactivar reutiliza el mismo registro de services; no crea otro.
4. La creación por lote vuelve a comprobar si el servicio existe antes de insertar.
5. Si el giro del negocio quedó bloqueado en onboarding, el selector de giro
   de Servicios queda bloqueado y se sincroniza con el giro real del negocio.
6. No cambia tablas, no borra servicios y no modifica servicios de otros negocios.

ARCHIVO NUEVO
-------------
js/admin-services-template-guard.js

PASO ÚNICO EN admin/servicios.html
---------------------------------
Busca esta línea:

<script src="../js/admin-services.js"></script>

Justo DESPUÉS agrega:

<script src="../js/admin-services-template-guard.js"></script>

Debe quedar así:

<script src="../js/admin-services.js"></script>
<script src="../js/admin-services-template-guard.js"></script>
<script>document.addEventListener("DOMContentLoaded",()=>window.lucide?.createIcons());</script>

IMPORTANTE
----------
No reemplaces admin-services.js.
No ejecutes SQL para este ajuste.
No borres servicios existentes.

PRUEBA DESPUÉS DE SUBIR
-----------------------
1. Abre MyCitaGo > Servicios.
2. En CLINICA EL DIENTE, el giro debe quedar en Dentista y bloqueado si ya fue confirmado.
3. "Valoración dental" y "Limpieza dental" deben mostrarse como "Editar" si están activas.
4. Si desactivas una de ellas, la plantilla debe cambiar a "Reactivar".
5. Al pulsar "Reactivar", debe volver a activar el MISMO registro.
6. No debe aparecer un segundo registro con el mismo nombre.

REDISEÑO VISUAL
---------------
No forma parte de este hotfix. Se deja para la fase visual posterior,
como se acordó.
